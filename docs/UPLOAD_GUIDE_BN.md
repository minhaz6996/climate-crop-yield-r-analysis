# GitHub Upload Guide (বাংলা)

**সতর্কতা:** Dataset প্রকাশের অনুমতি আগে যাচাই করুন। নিশ্চিত না হলে `data/` GitHub-এ upload করবেন না। আপনার Research, Manuscript Writing ও R Analysis-এর কাজ Portfolio-তে সঠিকভাবে উল্লেখ করুন; এটি নিজের ডিগ্রির জন্য আনুষ্ঠানিকভাবে জমা দেওয়া Thesis হিসেবে উপস্থাপন করবেন না।

1. GitHub-এ `climate-crop-yield-r-analysis` নামে **Public** repository তৈরি করুন; initial README ছাড়া তৈরি করলে একবারে ZIP-এর folder structure upload সহজ হবে।
2. ZIP Extract করুন। `README.md`, `assets`, `src`, `figures`, `results`, `docs` — এসব repo root-এ আপলোড করুন। `data/` যুক্ত করবেন কেবল dataset redistribution অনুমতি নিশ্চিত হলে।
3. GitHub-এর **Add file > Upload files** দিয়ে folder structure drag & drop করুন (ভেতরের ফাইলগুলো সহ)।
4. **Commit changes** দিয়ে নতুন repo-এর README ও image paths দেখুন।
5. আপনার কম্পিউটারে R থাকলে repo-এর root folder থেকে `Rscript src/analysis.R` চালিয়ে যাচাই করুন (ডেটাসেট local `data/` folder-এ থাকতে হবে)।
6. তারপর Main Profile-এর `minhaz6996/minhaz6996/README.md`-এ এই নতুন Project-এর link যুক্ত করুন।
